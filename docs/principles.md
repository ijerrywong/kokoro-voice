# 调音原理

这份文档说明：为什么只调几个参数，就能让一个成年人的声音听起来像小孩、老人或怪兽；耳朵靠什么分辨不同的人；以及每个参数在技术上是怎么实现的。
操作层面的速查表（配方、听感反馈对照）在 [references/voice-params.md](../references/voice-params.md)。

---

## 1. 声音是怎么产生的：声源 + 滤波

语音学里最常用的模型叫**声源–滤波模型**（source–filter model）：

```
声带振动（声源）  ──→  声道：喉咙 → 口腔 → 嘴唇（滤波器）  ──→  我们听到的声音
   决定「音高」                决定「共鸣 / 音色」
```

- **声源**：声带每秒开合的次数就是基频（F0），我们听到的是**音高**。声带越短越薄，振动越快，音高越高。
- **滤波器**：声道是一根有长度的管子，它会放大某几个频率，这些被放大的峰叫**共振峰**（formant，F1、F2、F3…）。管子越短，共振峰的频率越高。元音能被分辨出来，靠的就是共振峰的位置；**听起来是"大个子"还是"小个子"，靠的也是它**。

这两件事在生理上是相互独立的：同一个人可以用高音或低音说话（声源变了），但声道长度基本不变（滤波器没变）。所以耳朵能分开感知这两样东西。

## 2. 耳朵靠哪些线索判断"这是谁"

| 线索 | 成年男 | 成年女 | 小孩（5–10 岁） | 老人 |
|---|---|---|---|---|
| 音高（F0 中位数） | ~110 Hz | ~200 Hz | ~250–300 Hz | 男性略升、女性略降，抖动增加 |
| 共鸣（声道长度） | 最长 | 比男性短 ~15% | 比成年女性再短 ~15–25% | 基本不变，略低 |
| 语速 / 停顿 | 正常 | 正常 | 慢、一词一顿 | 慢 |
| 语调起伏 | 中 | 中偏大 | 大（兴奋时尤其明显） | 小、平 |
| 亮度（高频比例） | 偏暗 | 中 | 偏亮、胸腔低音少 | 偏暗、气声多 |

（数值是常见文献里的大致范围，个体差异很大，只用来理解方向。）

几个推论：

- **只升音高，不升共鸣** → 听起来像"大人捏着嗓子说话"。耳朵从共鸣里听出声道还是成年人的长度。
- **只升共鸣，不升音高** → 像一个"缩小版的成年人"，有点怪。
- **两者一起升**，再配上更慢的语速和更大的起伏 → 才开始像小孩。
- 反过来，两者一起降，再放慢、压平起伏 → 巨人、怪兽。

**结论：像不像，取决于几条线索是否彼此一致。** 调音就是让这几条线索都指向同一个"身体"和"性格"。

## 3. 认人与分类：各条线索的分量

第 2 节列出了线索。它们在两件事上分量不同：**认出这是哪个人**，以及**判断这是哪一类人**（男、女、孩子）。

### 认人：音高最不可靠

人和人之间的音高差得不多，范围大面积重叠：成年女性大多在 165–255 Hz，同性别的两个人常常只差几十赫兹，同一个人情绪一变，差得比这还多。所以耳朵认人主要不靠音高，大致按重要性排序：

| 层次 | 是什么 | 来源 | 本项目里对应 |
|---|---|---|---|
| 音色（共鸣） | 声音"像谁"的核心 | 声道长度和形状，每人都不同 | `voice` 底子、`formant` |
| 嗓音质地 | 沙哑、气声、明亮、挤压感 | 声带怎么振动 | 主要由 `voice` 底子带来；`bright` 只能粗略模拟 |
| 说话习惯 | 节奏、停顿、语调起伏、口音 | 后天养成 | `speed`、`range`、`lang` |
| 音高 | 高还是低 | 声带长短、厚薄、松紧 | `pitch` |

电话里一个"喂"就能听出是妈妈，靠的是她独特的共鸣和腔调，不是她的音高比别人高几赫兹。

### 分类：先有生理差异，分界线是学来的

男声、女声、童声不完全是约定俗成的，背后有实打实的生理差异：

| | 声带 → 音高（F0） | 声道长度 → 共鸣 |
|---|---|---|
| 成年男性 | 长而厚，约 85–180 Hz | 约 17 cm |
| 成年女性 | 短而薄，约 165–255 Hz | 约 14–15 cm |
| 儿童 | 更短更薄，约 250–400 Hz | 约 10–12 cm |

但"听多了才会分"也是对的，有三层意思：

1. **分界线是从经验里学来的。** 男女的音高在 160–180 Hz 一带重叠，单凭音高判断不了。大脑会把音高、共鸣、说话方式放在一起，按经验做综合判断。
2. **共鸣比音高更有决定性。** 男人用假声捏高嗓子，听起来通常还是男人，因为声道长度没变。反过来，只把女声的音高降下来，听起来像"压着嗓子的女人"，而不像男人。
3. **文化也会塑造它。** 有研究发现，日本女性说话的平均音高明显高于部分欧洲国家的女性，这是社会期待造成的差别，不全由生理决定。

### 对本项目的推论

- **身份和类别靠底子与共鸣，音高只能辅助。** 想让听众把两个角色当成两个人，底子或共鸣至少要有一样明显不同。只差音高的两个角色，听起来像同一个人换了情绪。`batch.py` 会对这种组合给出警告。
- **改性别、改年龄，先动共鸣，再让音高跟上。** 听众说"性别听不出来"时，先查 `formant`，而不是继续推 `pitch`。
- **嗓音质地基本由底子决定。** 沙哑、气声这类特点，后期参数几乎加不出来，只能靠选对底子或混合。所以选底子是最重要的一步（见第 7 节）。
- **"像不像"受听众的经验影响。** 不同地区的听众对"小女孩该多尖""老人该多慢"的预期不同。配方只是起点，最终以目标听众的耳朵为准。

## 4. 本项目的三个处理阶段

```
台词 ──→ ① Kokoro 模型 ──→ ② Praat 变形 ──→ ③ ffmpeg 滤波 ──→ mp3 / wav
          voice, speed       formant, pitch,     highpass, bright
                             range
```

### ① Kokoro 模型阶段：`voice`、`speed`

Kokoro-82M 是一个基于 StyleTTS 2 的模型。每个预设声音（如 `af_bella.pt`）其实是一组**风格向量**：

- 形状是 510 × 256。合成时按这句话的音素个数取其中一行（`pack[len(phonemes) - 1]`），所以长短不同的句子用的向量略有不同。
- 每行 256 维里，**前 128 维交给解码器，决定音色**；**后 128 维交给韵律预测器，决定节奏和语调风格**。

**`voice` 混合**：`{"am_puck": 0.5, "af_bella": 0.5}` 就是把两个声音的向量按权重相加。因为向量空间是连续的，相加的结果是一个"介于两者之间"的新声音，音色和说话风格都会居中。这是唯一一个在**模型内部**改音色的方法，所以听起来最自然。代价是结果不可预测，只能试听。

**`speed`**：模型先预测每个音素该念多长，再把这个时长除以 `speed`。语速是模型自己按新节奏"念"出来的，不是把录音事后拉长或压缩，所以放慢到 0.8 也不会有拖音感。

### ② Praat 变形阶段：`formant`、`pitch`、`range`

用的是语音分析软件 Praat 里的 **Change gender** 功能（通过 Python 绑定 parselmouth 调用），步骤是：

1. **改共鸣**：把声音按 `formant` 倍数**重新采样**。这一步会让整段声音的频率一起变高，共振峰也就一起上移，效果等于"声道变短了"。这一步会顺带改变音高和时长。
2. **重设音高**：用 **PSOLA**（基音同步叠加）技术，按每个声门周期切成小片段，再用新的间隔叠回去。这样只改音高，不动共振峰。我们先量出原声的音高中位数，再乘以 `pitch` 倍数作为目标值。
3. **改起伏**：在第 2 步里，音高曲线相对中位数的偏离幅度乘以 `range`。比如 >1 时，高的地方更高、低的地方更低。
4. **还原时长**：PSOLA 同时把第 1 步造成的时长变化抵消掉，最终**时长和原来完全一样**。所以 Kokoro 给出的每个词的时间仍然准确，跟读高亮不受影响。

实测（底子 am_liam，同一句话）：

| 设置 | 音高中位数 | 时长 |
|---|---|---|
| 原声 | 112 Hz | 2.42 s |
| pitch ×1.5 | 168 Hz | 2.42 s |
| formant ×1.25 | 114 Hz（音高不变） | 2.42 s |
| pitch ×1.5 + formant ×1.25 | 169 Hz | 2.42 s |

可以看到，音高和共鸣确实是分开控制的，时长也不变。

### ③ ffmpeg 滤波阶段：`highpass`、`bright`

- **`highpass`**：切掉某个频率以下的声音。小孩、小生物胸腔小，低频共鸣少，切掉 100–200 Hz 以下会让声音显得"薄"、显得小。
- **`bright`**：3 kHz 以上加减若干分贝。加了更脆、更亮，像小孩或卡通；减了更闷、更柔，像老人或隔着东西说话。

这两项只改频谱的平衡，不改音高和共鸣的位置，属于"上色"。

## 5. 对照：早期的做法为什么不够

本项目最早只用 ffmpeg 的 `asetrate` 来变调：先假装采样率变高（声音像快放的磁带，变尖也变快），再用 `atempo` 把速度拉回来。

问题在于第一步把**音高和共鸣绑在一起**，按同一个倍数上移：

- 优点是简单。而且一起上移本身就有"变小"的效果，所以大致能用。
- 缺点是没法单独调。比如想要"共鸣像小孩、音高别太尖"，就做不到。倍数一大，两样一起过头，就出现"花栗鼠"音。

Praat 那一步把这两件事拆开了，这是现在能做出多种童声的关键。

## 6. 失真从哪来、上限在哪

- **共鸣上移过多**（formant > ~1.35）：重新采样把高频推到了很高的地方，声音发虚、有金属感。
- **音高变化过多**（尤其男声 pitch > ~2）：PSOLA 切出的片段之间衔接不自然，出现颤音、机器感。所以做童声时优先用**女声或混合声当底子**，变形幅度可以小一点。
- **模型本身的局限**：Kokoro 的声音都是成年人录音训练出来的。不管怎么变形，**咬字方式、节奏习惯仍然是成人的**，比如小孩常见的发音不准、气息不稳，都模拟不出来。追求高度真实，需要用儿童语料训练的模型。

## 7. 调音的一般方法

1. **先选底子**：底子决定 80% 的感觉。目标是女孩，就从女声开始；目标在男女之间，就混合。
2. **再定"身体大小"**：`formant`。
3. **然后定音高**：`pitch`。让它和身体大小相匹配，不要比共鸣跑得更远。
4. **最后加性格**：`speed`、`range`、`highpass`、`bright`。
5. **有多个角色时，查一遍区分度**：每两个角色之间，底子或共鸣至少要有一样明显不同（见第 3 节）。只靠音高区分是不够的。
6. **每次只改一两项**，并且同一句台词前后对比。否则分不清是哪个改动起了作用。
7. **用真实场景的台词来试听**。一句"Hello"听着不错，换成长句、问句、感叹句，可能就露馅了。
