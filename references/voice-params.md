# 声音参数手册

设计候选声音、把用户的听感反馈翻译成参数时读这一份。

## 耳朵靠什么判断"这是谁"

| 线索 | 物理来源 | 例子 |
|---|---|---|
| 音高 | 声带每秒振动次数 | 成年男 ~110Hz，成年女 ~200Hz，小孩 ~250–300Hz，老人波动大、略降 |
| 共鸣（formant） | 声道（喉到嘴唇）长度，越短共振频率越高 | 判断"身体多大"的主要依据。小孩声道短约 20–30% |
| 语速、停顿 | 说话习惯 | 小孩慢、一词一顿；老人慢；卡通角色快 |
| 语调起伏 | 情绪与年龄 | 小孩兴奋时起伏大；疲惫、老人、机器更平 |
| 亮度 | 频谱高低频比例 | 小孩、小生物胸腔低音少、偏亮；老人、巨人偏闷 |

关键：**只升音高不升共鸣 = 大人捏嗓子**；只升共鸣不升音高 = 怪异的"小号成年人"。像小孩需要两者一起升，再配合语速和起伏。

## 参数

| 参数 | 阶段 | 范围 | 说明 |
|---|---|---|---|
| `voice` | Kokoro 模型 | 声音名，或 `{"a": 0.6, "b": 0.4}` | 混合 = 声音特征向量按比例相加，得到介于两者之间的新声音。口音跟权重最大的那个（a 美音 / b 英音），也可用 `lang` 强制 |
| `speed` | Kokoro 模型 | 0.5–1.5 | 模型直接按此语速生成，自然，不是事后拉伸 |
| `formant` | Praat | 0.8–1.45 | >1 声道变短 = 更小的身体；<1 = 更大的身体。超过 ~1.35 开始失真 |
| `pitch` | Praat | 0.6–2.4 | 只改音高（中位数 × 倍数）。女声底子做小孩 ×1.2–1.4；男声底子要 ×1.7–2，失真更明显 |
| `range` | Praat | 0.3–2.5 | 语调起伏幅度。>1 活泼夸张，<1 平淡 |
| `highpass` | ffmpeg | 0–400 Hz | 低切，0 = 关。100–200 让声音变薄 |
| `bright` | ffmpeg | −8–+10 dB | 3kHz 以上增益 |

Praat 那三项保持时长不变，所以词时间仍然准确。

## Kokoro 英语声音（28 个）

- 美式女 `af_`：alloy aoede bella heart jessica kore nicole nova river sarah sky
- 美式男 `am_`：adam echo eric fenrir liam michael onyx puck santa
- 英式女 `bf_`：alice emma isabella lily
- 英式男 `bm_`：daniel fable george lewis

官方质量评级较高的是 af_heart、af_bella，其次 af_nicole、bf_emma 等；做变形时优先选清晰、自然的底子。首次用到某个声音会自动下载（每个 ~0.5MB）。

## 配方起点

| 目标 | 底子 | speed | formant | pitch | range | 其他 |
|---|---|---|---|---|---|---|
| 5 岁左右 | 女声 | 0.85 | 1.25 | 1.4 | 1.2 | highpass 150 |
| 7–8 岁女孩 | 女声 | 0.9 | 1.18 | 1.3 | 1.4 | highpass 120, bright +2 |
| 7–8 岁男孩 | 男女混合 0.5/0.5 | 0.9 | 1.2 | 1.5 | 1.3 | highpass 120 |
| 10–12 岁男孩 | 男 0.7 + 女 0.3 | 0.9 | 1.12 | 1.7 | 1.15 | |
| 青少年 | 原性别 | 1.0 | 1.06 | 1.1 | 1.1 | |
| 老人 | 原性别 | 0.82–0.88 | 0.96 | 0.9 | 0.75 | bright −2 |
| 巨人 / 怪兽 | 低沉男声 | 0.8 | 0.82 | 0.7 | 0.7 | |
| 卡通小生物 | 女声 | 1.05 | 1.35 | 1.6 | 1.5 | highpass 200, bright +3 |
| 机器人感 | 任意 | 0.95 | 1.0 | 1.0 | 0.3 | |

小孩不分男女时声音差别很小；男孩、女孩的区分主要靠底子音色、语气活泼程度，而不是音高。

## 听感反馈 → 调哪里

| 用户说 | 先调 | 再考虑 |
|---|---|---|
| 不像小孩 / 像大人装的 | formant +0.05 | pitch 别再升，可能已经过头 |
| 太尖 / 刺耳 | pitch −0.1 | bright −2 |
| 像花栗鼠 / 机器味 / 有颤音 | formant 和 pitch 都退回一些 | 换女声底子，减少变形幅度 |
| 再小一点 / 更年幼 | formant +0.05，speed −0.05 | pitch +0.1 |
| 再大一点 | formant −0.05 | pitch −0.1 |
| 更活泼 / 更兴奋 | range +0.2 | speed +0.05 |
| 太夸张 / 太做作 | range −0.2 | |
| 太平 / 像机器 | range +0.2 | 换底子声音 |
| 太快 / 听不清 | speed −0.1 | |
| 太闷 / 糊 | bright +2 | highpass +50 |
| 太薄 / 没分量 | highpass 降到 0 | bright −1 |
| 更像男孩 | 混合里提高男声比例 | 换 am_puck / am_liam 底子 |
| 更像女孩 | 混合里提高女声比例 | 换 bf_lily / af_sky 底子 |
| 口音不对 | 换 a↔b 开头的底子，或设 `lang` | |

每轮只动 1–2 个参数，否则用户分不清哪个变化起了作用。

## 局限（要如实告诉用户）

- 这是在成人声音上模拟。咬字、节奏仍然是成人的，追求高度真实的童声需要专门的儿童语料模型。
- 变形越大，PSOLA 的机器味越重。formant > 1.35 或男声 pitch > 2 时尤其明显。
- Claude 听不到声音。参数只是起点，好不好由用户的耳朵决定。
